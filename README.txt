HAMU STRIKE

EASY START:
1. Extract the entire ZIP.
2. Open the hamu-strike folder.
3. Double-click START_GAME.bat.
4. It will automatically start the local server AND open the game in Chrome.
5. Do NOT open START_GAME.bat from a browser address bar.

CLASH SQUAD:
The existing assets/models/csmap.glb is included and is loaded by Clash Squad through the local server.

If Chrome was already showing localhost:8000/START_GAME.bat, close that tab and simply double-click START_GAME.bat once.
